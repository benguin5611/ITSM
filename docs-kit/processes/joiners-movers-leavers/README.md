# Joiners / Movers / Leavers

> Part of the [docs-kit](../../README.md#before-you-rely-on-anything-here), a Department-of-One starting point, not a certified or audit-ready control out of the box. Read that disclaimer before relying on it.

The cross-functional workflows for the three highest-frequency, highest-risk identity events. Each process is an end-to-end diagram spanning recruitment, HR, payroll, and IT, paired with the hands-on procedure covering the IT slice of it:

- [Joiners (onboarding) process](joiners-process.md) (procedure: [joiners.md](../../procedures/joiners-movers-leavers/joiners.md))
- [Movers (role change) process](movers-process.md) (procedure: [movers.md](../../procedures/joiners-movers-leavers/movers.md))
- [Leavers (offboarding) process](leavers-process.md) (procedure: [leavers.md](../../procedures/joiners-movers-leavers/leavers.md))

The diagrams deliberately include steps outside a solo IT operator's remit (advertising a role, payroll, exit interviews) so the IT work has its surrounding context. The paired procedure is the part an operator actually executes, and each one links back to the workflow it sits inside.
